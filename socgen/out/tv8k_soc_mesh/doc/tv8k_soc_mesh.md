# tv8k_soc_mesh

Generated by socgen from `socgen/specs/tv8k_soc.yaml`. 8K HDTV SoC with 12 AXI masters, 5 IOMMUs, a 4x4 mesh NoC, 8 LPDDR5 ports and an APB peripheral bus

NoC: generated RTL `tv8k_soc_mesh_noc` (4x4 mesh of orca_noc_router (open router when xuanji-core is not fetched), XY routing). Zero-load single-beat read = 5 + 4 + 2*hops + access cycles, plus the AMBA adapters (axi4lite 2, ahb 4, apb 5). Clock 10.0 ns.
